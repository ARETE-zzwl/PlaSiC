# 6.5 Cold-Start Surface Boundary Fields at T42 { #cold-start-surface-fields-t42 }

When PlaSiC is started **without** `--restart`, it
builds the atmosphere, the land surface, the sea ice and the ocean from a directory of NetCDF
**surface boundary files** named by `--data-dir`. This note documents every field of that
directory for the standard T42 configuration (`src/data/surface/T42/`) and shows the spatial
distribution of each one, month by month where the file carries months.

## 0. The Eight Files Behind a Cold Start

Every file holds one variable, `surface(time, lat, lon)`, and carries
global attributes (`field_name`, `spectral_truncation`, `latitude_count`, `longitude_count`,
`surface_format_version`, `source_sha256`) that the loader verifies before the data are accepted.

**Table 6.5.1.** The eight T42 surface boundary files. "Records" is the length of the `time`
dimension; "stored unit" is the unit of the data as delivered.

| Field `surface` | File (in `T42/`) | Records | Stored unit | 
|---|---|---:|---|
| `orography` | `N064_surf_orography.nc` | 1 | m² s⁻² (geopotential) | 
| `land_sea_mask` | `N064_surf_land_sea_mask.nc` | 1 | fraction | 
| `surface_temperature` | `N064_surf_surface_temperature.nc` | 14 | K | 
| `sea_ice_cover` | `N064_surf_sea_ice_cover.nc` | 14 | % (0–100) | 
| `roughness_length` | `N064_surf_roughness_length.nc` | 1 | m | 
| `background_albedo` | `N064_surf_background_albedo.nc` | 14 | fraction | 
| `glacier_fraction` | `N064_surf_glacier_fraction.nc` | 1 | fraction | 
| `soil_water_capacity` | `N064_surf_soil_water_capacity.nc` | 1 | m | 

Two conventions apply to the whole set:

- The grid is the **Gaussian grid of the truncation**: latitudes are the 64 Gaussian nodes, ordered
  north to south, longitudes are uniform from 0° to 357.1875°E (Δλ = 2.8125°). The file stores
  `float64` values; the loader reads them as single precision.
- Every field is **globally defined**. As explained in Section 7, the land fields were extended to
  sea points when the source data were built, so roughness, albedo or water capacity are not zero
  over the ocean. PlaSiC reads them globally but only the land values enter the model physics.

## 1. The 14-Slot Monthly Layout

Three fields carry monthly climatologies. They are not stored as 12 months but as **14 slots**,
with the December and January fields duplicated at the ends so that a continuous cycle has no year
boundary:

$$
\underbrace{\text{Dec}}_{\text{slot }0},\;
\text{Jan},\text{Feb},\dots,\text{Nov},\text{Dec},\;
\underbrace{\text{Jan}}_{\text{slot }13}.
\tag{6.5.1}
$$

The `time` coordinate of the NetCDF file encodes the same offsets (`−1` for the previous December,
`0 … 11` for January to December, `12` for the next January). `momint()` (`src/tools/calmod_kernels.c`) returns the two months that bracket the current model
date and their interpolation weight, and the returned month number *is* the slot index. A date in
the second half of a month blends that month with the following slot (December → slot 13); a date
in the first half blends it with the preceding slot (January → slot 0). The two halo slots exist
exactly for these two cases.

A cold start reads the complete cycle but then seeds the state from **one** slot: the start month
`plasic_ndatim[1]` (= 1…12 for January…December) selects the fields. From the first time step on,
the monthly fields follow the model date and are interpolated between their two bracketing slots
(`land_interpolate_climatology()` and `land_interpolate_albedo()` in
`src/land/landmod_kernels.c`, `ice_interpolate_climatology()` and `ocean_interpolate_cycle()` in
`src/sea/`).

## 2. What the Loader Changes Before the Fields Enter the Model

The raw files are the source of truth, but PlaSiC applies a small set of transformations at load
time. Table 6.5.2 lists them; all of them are reproduced in the figures (the monthly sea-ice maps,
for instance, show the normalized cover, not the percent values of the file).

**Table 6.5.2.** Load-time transformations of the T42 surface fields.

| Field | Transformation | Effect in the model |
|---|---|---|
| `land_sea_mask` | $d_{ls} = \mathbb{1}\!\left[f_{ls} > 0.5\right]$ | binary land mask `plasic_dls`; also copied into the ice and ocean modules |
| `glacier_fraction` | $d_{glac} = \mathbb{1}\!\left[f_{glac} > 0.5\right]$ | binary glacier mask `plasic_dglac`, used by the land energy balance |
| `sea_ice_cover` | $c = \min\!\left(1, \max\!\left(0, 10^{-2} c_{\%}\right)\right)$, then $c \leftarrow 0$ on land | fractional cover in [0, 1] |
| `surface_temperature` | $T_{s} \leftarrow \max(T_{s}, 271.25\ \mathrm{K})$ for the ocean copy | sea-surface temperature never falls below the freezing point in the ocean/ice module |
| `soil_water_capacity` | none; $W_{\max} > 0$ assumed | initial bucket water $W_0 = 0.25\,W_{\max}$, wetness $\beta = \min(1, W/(0.4W_{\max}))$ |
| `orography` | surface geopotential $\Phi = gz$ → spectral coefficients, non-dimensionalised by $(a\Omega)^2$; then $\pi_{lm} = -\Phi_{lm}/(R_dT_{gr})$ fills **every mode except the global mean $(0,0)$** | terrain enters the dynamics through $\pi = \ln(p_s/p_0)$ with $T_{gr} = 288$ K; the mean topography is folded into the reference pressure $p_0$ ([Eq. (6.5.2)](#3-reference-pressure-and-the-initial-atmospheric-state)), not carried by $\pi$ |
| `background_albedo` | linear blend of the two bracketing slots at every step | snow-free background for the snow/glacier albedo formula |
| `surface_temperature` | the one 14-slot field (AMIP-II surface temperature, defined over land as well as sea) is copied to the land, ice and ocean modules at load time; the cold start takes the **start-month slot** (`plasic_ndatim[1]`) and seeds: land points $T_s$ = slot value, the same value also filling the snow temperature, the leapfrog old level and all five soil layers $T_1=\dots=T_5$; sea points $T_{oc}$ = slot value (ocean copy, floored at 271.25 K) and $T_{ice}$ = slot value (ice copy); the land copy keeps the $10^{20}$ "no land" sentinel at sea points | one field, three consumers: $T_s$ + $T_1\dots T_5$ are the land skin and soil temperatures (isothermal at start, then evolving under the land energy balance), $T_{ice}$ the sea-ice surface temperature, $T_{oc}$ the slab-ocean mixed-layer SST; the ice and ocean copies are interpolated between the two bracketing months (`ice_interpolate_climatology()`, `ocean_interpolate_cycle()`) |
| `sea_ice_cover` | `ice_make_thickness()` maps cover to an initial ice thickness (0.25–3 m north of the equator, 0.25–0.5 m south) | ice thermodynamics starts from a plausible thickness, not from zero |

The fill starts at the $(1,0)$ mode: only the global mean $\pi_{00}$ stays zero, because
the dynamics holds the $(0,0)$ mode of $\pi$ fixed as the mass reference
(`surface_log_pressure[0] = surface_log_pressure[1] = 0` in
`src/dynamical_core/plasic_kernels.c`). The mean effect of the topography is therefore
absorbed in the reference pressure, $p_0 \leftarrow p_0\exp(-\Phi_{00}U^2/(\sqrt2\,R_dT_{gr}))$, so a planet with a higher mean topography starts with a
lower reference pressure. The physical reading is local: a high plateau means a thin air
column and hence a low surface pressure, from the first step on.


## 3. Reference pressure and the initial atmospheric state

The scalar reference pressure starts at \(101100\ \mathrm{Pa}\) and is then corrected for
the global-mean surface geopotential. The runtime operation is

$$
p_0
=101100\exp\!\left(-\frac{\overline{\Phi_s}}{R_dT_{\mathrm{gr}}}\right).
\tag{6.5.2}
$$

In the supplied surface files the mean can be evaluated directly with the Gaussian quadrature weights,

$$
\overline{\Phi_s}=\frac12\sum_i w_i\,\langle\Phi_s(\varphi_i,\lambda)\rangle_\lambda.
\tag{6.5.3}
$$

**Table 6.5.3.** Resolution-dependent reference pressure evaluated from the orography file used by
each cold start. The pressure is the corrected \(p_0\), not the local surface pressure \(p_s\).

| Resolution | Gaussian grid | \(\overline{\Phi_s}\) (m² s⁻²) | corrected \(p_0\) (Pa) | initial \(\lvert\mathbf{V}\rvert\) (m s⁻¹) |
|---|---:|---:|---:|---:|
| T21 | 32 × 64 | 2269.3901 | 98361.97 | 0.00 |
| T31 | 48 × 96 | 2271.1951 | 98359.90 | 0.00 |
| T42 | 64 × 128 | 2272.0391 | 98358.86 | 0.00 |
| T85 | 128 × 256 | 2274.4766 | 98355.95 | 0.00 |


The resolution dependence is small (about \(6\ \mathrm{Pa}\) from T21 to T85) because the four
files describe the same orography at different truncations; T85 is the supplied bilinear
regridding of the T42 field. The pressure field itself is spatially varying: the non-mean modes
are initialized as

$$
\widehat\pi_{nm}=-\frac{U^2}{R_dT_{\mathrm{gr}}}
\widehat\Phi_{nm}^{\,\mathrm{nd}},
\qquad (n,m)\ne(0,0),
\tag{6.5.4}
$$

so high terrain has lower \(p_s=p_0e^\pi\), while the mean mode of \(\pi\) remains zero.

### 3.1 Why the initial wind speed is exactly zero

The cold-start routine stores the **absolute** vorticity, not relative vorticity alone. At every
atmospheric level it writes the real \((m=0,n=1)\) coefficient as

$$
\widehat\eta_{10}=c_{Y_{10}},
\qquad c_{Y_{10}}Y_1^0=2\sin\varphi,
$$

and leaves all divergence coefficients and all other vorticity modes at zero. Before the
spectral inversion, `sht_vortdiv_to_wind()` subtracts the same planetary coefficient from that
mode. The inversion therefore receives zero relative vorticity and zero divergence, giving

$$
u(\varphi,\lambda,k)=v(\varphi,\lambda,k)=0,
\qquad |\mathbf{V}|=0\ \mathrm{m\,s^{-1}}.
\tag{6.5.5}
$$

at every Gaussian grid point and every level for T21, T31, T42 and T85. A spatial map of the
initial wind would consequently be a featureless zero field.

## 5. The Surface-Temperature Climatology

![The 14-month surface-temperature climatology](<../assets/images/t42-surface-temperature-months.png>)

Figure 6.5.2. Surface-temperature climatology, one map per slot of the 14-month cycle (**a** `Dec*`,
**b** `Jan`, …, **n** `Jan*`), with an area-weighted summary (**o**). The colour scale is centred on
the melting point 273.16 K: blue is at or below freezing, red is above. The field is the AMIP-II

temperature and for the sea/ice surface. 

## 6. The Sea-Ice Cover Climatology

![The 14-month sea-ice cover climatology after normalization](<../assets/images/t42-sea-ice-cover-months.png>)

Figure 6.5.3. Sea-ice cover climatology over the 14-month cycle, drawn after the loader's
normalization (percent ÷ 100, clipped to [0, 1], zero over land); the ice-free ocean is white, land
is beige. **o**, area-weighted mean cover of the two hemispheres.

The source file is a percentage field. Its interpolation to the Gaussian grid created undershoots:
3137 of the 114 688 stored cells (2.74 %) are negative, down to −83 %; the loader clips them to
zero together with any value above 100 %. Values above 100 % do occur (up to 108 %), which is why
the loader contains a second protection that rescales any file whose maximum exceeds 5 before the
clip is applied. The maps of Figure 6.5.3 are the fields the model actually sees.

## 7. The Snow-Free Background Albedo

![The 14-month background albedo climatology](<../assets/images/t42-background-albedo-months.png>)

Figure 6.5.4. Snow-free background albedo over the 14-month cycle, drawn only over land, with an
area-weighted land mean (**o**). This is the albedo of the bare or vegetated surface without snow,
so it is almost time-invariant in the data set: the land mean varies by only 0.005 (0.221–0.225)
through the year, and the 14 maps differ mainly through the faint seasonality of the northern
vegetation. The large seasonal albedo changes of the model are produced elsewhere: at run time the
land module blends this field with a temperature-dependent snow/glacier albedo as soon as the snow
reservoir is non-empty ([4.2](../4-model-and-coupling/4.2-land-surface-module.md) §8), and the ocean
albedo is prescribed separately ([9.6](../9-appendix/9.6-physical-constants.md) §8).

The absence of strong seasonality in this particular field is itself worth noting: it is the reason
the model's albedo feedback is carried by the snow reservoir and the glacier mask, not by the
prescribed background.
