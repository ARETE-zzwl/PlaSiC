# 9.5 C Language Primer { #c-language-primer }

This appendix is addressed to readers who arrive at PlaSiC **without any C programming background**. It deliberately does not teach C itself; instead, it points you to a course we trust, and explains what parts of C matter most for this project.

## 1. Why C comes first here

Nearly everything in this project is C:

- The numerical core under `src/` is written in C11, compiled with `gcc`/`make`, and uses pointers, arrays, and manually managed memory throughout.
- The dynamical core chapters (Chapter 2) and parameterization chapters (Chapter 3) discuss equations and algorithms *as implemented in C*, so reading the code is part of reading the documentation.
- The desktop application (Chapter 8) keeps the same split: a Python/PySide6 front end drives the C core.

If you come from Python, MATLAB, or Julia, the syntax may look familiar at first. The parts that will not transfer automatically are exactly the parts this project relies on the most: **pointers, memory layout, manual allocation, and the compile/link workflow**. Learn those properly before continuing.

The language standard used here is ISO/IEC 9899:2011 (C11; ISO/IEC, 2011); the classic textbook reference is Kernighan and Ritchie (1988).


## 2. The tutorial we recommend

We recommend the following free, well-organized C language course:

**<https://subingwen.cn/categories/C%E8%AF%AD%E8%A8%80/>**

It is published on the site *爱编程的大丙* (subingwen.cn), which is a well-known Chinese-language programming education site. 

The same site also provides video lessons and companion courses on C++, Linux, Qt, and data structures, so it can support you well beyond the C basics.

!!! warning "The tutorial is in Chinese"
    At the moment the tutorial is written in Chinese. If you do not read Chinese, any equivalent introductory C course will do, as long as it covers **pointers and memory** thoroughly. The concepts are the same everywhere; what matters is that you practice until pointers stop feeling like magic.


## 3. What to do next

Once you can read a C file without getting lost, return to [1.1 Running PlaSiC first!](../1-user-guide/1.1-Running-PlaSiC-first.md) and continue with the main tutorial. When you meet an unfamiliar C construct in the source code, look it up in the course rather than stopping—over time, the language will fade into the background and the physics will take the foreground.
