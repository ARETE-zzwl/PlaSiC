# 9.4 PySide6 and Qt in Brief { #pyside6 }

This page does not teach the Qt API or syntax. Desktop interfaces belong to general software engineering and are unrelated to the physics and numerical core of a climate model.

## 1. How Qt, PyQt, and PySide6 relate

- **Qt** is a cross-platform application development framework written in C++, maintained by the Qt Group and developed since the 1990s. It provides everything a desktop program needs—windows, widgets, painting, and the event loop—as well as non-GUI modules for networking, threads, files, and multimedia. It is one of the most mature GUI frameworks in industry, and the interfaces of many scientific applications are built on it.
- **PyQt** is a set of Python bindings for Qt provided by the company Riverbank Computing.
- **PySide6** is the official Qt for Python binding from the Qt Group, corresponding to Qt 6 and friendlier to both open-source and closed-source software. This is what the PlaSiC App uses.

In one sentence: **Qt is the core, and PyQt and PySide6 are two sets of interfaces that let Python call Qt**. The APIs of PySide6 and PyQt6 correspond almost one-to-one, so most tutorials can be read interchangeably; the differences are mainly licensing and a few naming details. The 5/6 in the name refers to the corresponding Qt major version: older projects may use PyQt5 or PySide2, while new projects should use PySide6.

## 2. When you need to care about it

- If you only run numerical experiments from the command line: you do not, and this page can be skipped.
- If you want to read or extend the PlaSiC App interface: you need some conceptual grounding in Qt, but there is no need to memorize the API—look up the official documentation whenever you meet a specific widget.
- If you want to write a small desktop tool for your own model or data: PySide6 is one of the most mature choices in Python.


## 3. How to keep learning

- Official documentation (recommended entry point): [Qt for Python documentation](https://doc.qt.io/qtforpython-6/). *Getting Started* covers installation and a first program, and *Modules API* is the reference manual for looking up specific classes.
