# 9.6 Physical Constants and Model Coefficients { #physical-constants }

This appendix is a single reference page for the physical constants and formula coefficients that are
hard-coded in the PlaSiC C sources. It answers a recurring question when reading the code or tuning an
experiment: *which number is a fixed property of the modelled planet, which number is a tunable
parameterization coefficient, and what does each one default to?*

Two kinds of quantities are listed together:

- **Physical constants** that describe the planet and the working fluid.
- **Formula coefficients** that appear inside parameterizations, for example the surface stability
  coefficients $B = C = D = 5.0$, the Charnock parameter $\alpha_{ch} = 0.018$, or the polynomial
  coefficients of the longwave water-vapour absorptivity.

The constants are grouped by module. Every value is single-precision unless stated otherwise, and the
"Default value" column gives the value used by the default build (`NLAT = 48`, `NLEV = 13`, 3-D ocean
with 16 deep levels). Values labelled *derived* are computed at run time from constants further up the
page. The originating files are named at the start of each section.

## 0. How to Read the Tables

| Column | Meaning |
|---|---|
| Symbol | Mathematical notation of the constant, as used in the equations. Where the literature has no standard symbol, a symbol is introduced in the "Definition" column. |
| Definition | The physical meaning, and the formula when the quantity is a coefficient rather than a standalone constant. |
| Default value | The value that is actually used by a default build. Values labelled *derived* are computed at run time. |
| Unit | SI units, or `1` for dimensionless quantities. |

## 11. Constants That Are Deliberately Absent

A few quantities that one might expect in a constants table are intentionally not hard-coded:

- **Pre-industrial CO₂ concentration.** There is no 278 ppm or 284.7 ppm literal anywhere in the
  C sources. The historical experiment is forced from the CMIP CSV table under
  `src/data/forcing/CO2/`, and the CLI default `co2_ppm` is 0.0, which means "no fixed concentration
  supplied"; either a fixed concentration or a forcing table must be given explicitly.
- **Air density.** No density constant exists. Air density is always diagnosed as $\rho = p/(R_dT)$
  from the local pressure and temperature. The only density constants are the material densities of
  liquid water (1000 kg m⁻³), seawater (1030 kg m⁻³), ice (920 kg m⁻³) and snow (330 kg m⁻³) listed
  above.
- **Legacy land fields.** The land albedo, roughness, wetness, maximum soil water and glacier height
  defaults are initialized but not read by the numerical kernels; the corresponding surface fields
  come from the NetCDF climatologies.
- **Legacy top sponge.** The top-of-model sponge damping scalar is declared with a "days" comment but
  is used directly as a rate, and it is only applied when its switch is enabled. The active sponge in
  the standard configuration is the Rayleigh friction $\tau_R(k)$ (20/100 days) described in
  Section 2.2.
